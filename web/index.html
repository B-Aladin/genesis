01 Reverse-engineering bench

Photos and a video in. A circuit you can check out.

GENESIS looks at an undocumented board, measures what the video shows frame by frame, matches it to a known circuit and tests that explanation against the device's real behaviour. Every sentence in the report cites the evidence behind it.

02 How an investigation runs

The models see and explain. Code measures and decides. You approve the values.

  1. 01Watch the video

    OpenCV measures brightness frame by frame and times every blink. No model involved.

    code
  2. 02Observe the parts

    A vision model lists every part, marking and colour band it can actually read.

    model
  3. 03Match a circuit

    Known circuits are scored clue by clue against the parts and the measured signal.

    code
  4. 04Check the prediction

    The winning circuit's formula predicts the blink rate from the parts; it has to match the video.

    code
  5. 05List what's unknown

    What pixels can't settle, and the single most useful thing to capture next.

    code
  6. 06Write the report

    Every sentence cites evidence. A skeptic flags any claim or number that isn't grounded.

    model + skeptic
